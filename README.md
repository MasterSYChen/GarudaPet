# GarudaPet · 大鹏金翅鸟桌宠

Windows 桌面宠物，**单文件 EXE、双击即用**，兼容 Win7 / Win10 / Win11，无需安装 Python 或任何运行库。

## 下载

到 **[Releases](https://github.com/MasterSYChen/GarudaPet/releases/latest)** 下载最新的 `GarudaPetV5.exe`，双击运行即可。

> 首次运行会在桌面显示桌宠；单击宠物散出快捷菜单，右键可打开设置。

## 自动更新

程序内置一键更新，不需要你手动来这个页面：

- 启动 8 秒后**自动检查**新版本（24 小时节流一次）；
- 也可以随时在桌宠上**右键 →「检查更新」**手动查；
- 发现新版本会用气泡提示，**点一下**即自动下载 → 校验 SHA256 → 重启完成更新。

更新走的就是本仓库的 [Releases](../../releases) 与根目录的 `version.json`，
下载后会用 SHA256 校验，**不一致绝不覆盖**。

自 **V20.50** 起，更新过程完全可见、可查：

- 更新包在**后台下载**（不会再把界面卡住），桌面右下角有**进度卡片**
  （百分比 / 体积 / 速度 / 预计剩余）；
- 覆盖前会等旧程序退出、必要时**先改名腾位**，失败会自动重试，仍失败则**回滚旧版**；
- 全过程写入 `%APPDATA%\GarudaPet\logs\update_apply.log`；
- 更新是否真的生效，由新版本启动后**自己算 SHA256 对账**并给出提示。

## 日志反馈

遇到问题时，可在程序「关于」页底部点**「日志反馈」**开始记录运行日志；
记录期间桌面右下角会出现一个常驻小卡片，**点它即可暂停**并自动生成日志文件
（保存在 `%APPDATA%\GarudaPet\log_capture\`，路径也会在提示气泡里告知）。

生成的日志会经 FormSubmit 免凭据转发给作者（**不需要你填任何账号或授权码**；
首次使用需在作者邮箱点一次激活链接，之后长期有效）。
